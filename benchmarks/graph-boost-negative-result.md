# 两个图谱加强检索方案的验证：BM25→BFS（单跳）与谓词表→DFS（谓词关系）

结论先说：**在当前 LoCoMo 记忆图上，两个方案都没有带来可归因的提升**。

- 方案 1（query 分词 → BM25 匹配实体 → 每个实体各自 BFS 加权）：单跳 gold 命中 **52.4% → 52.4%**（最佳配置），MRR **0.309 → 0.283**（变差）。端到端准确率 67.9% → 70.3%（+2.4pp），但把新增事实换成随机事实也能得到同样的 +5.3pp，同 prompt 复测 100 题翻转 6 题——增益来自上下文扰动与测量噪声，不是图。
- 方案 2（中英谓词对应表 → query 谓词匹配 → 谓词边优先 DFS）：谓词子集 gold 命中 **57.3% → 57.3%**，MRR 0.326 → 0.311。端到端 67.9% → 70.6%（+2.6pp），同样被随机事实对照完全解释（209 题上 s2 与随机对照同为 72.2%）。
- 根因是图的结构：**51.4% 的事实只挂在两个说话人 hub 上**，从实体出发根本到不了；谓词是"多实体共享交会点"而不是 subject→object 的有向边。基线漏掉的 199 道单跳题里，只有 **7 道**的 gold 落在 BM25 种子 2 跳内；谓词侧 112 道漏题里只有 **8 道**在 DFS 可达集内。

## 0. 数据核对（含一处与预期不符）

| 检查项 | 结果 |
| --- | --- |
| query embedding | `_locomo_bench/query_embeddings_all.jsonl`，999 行 × 1024 维；与 `_locomo_bench/_wsim/queries.npy` 逐行余弦 ≈ 0.999998~1；顺序与 5 个 `conv*/corpus.json` 的 QA 完全一致 |
| LoCoMo 记忆图谱 | `_locomo_bench/memos_system/data/graphiti/shared/topology.json`：8295 节点 / 7798 关系；5 个角色；**5058 条事实**；360 个实体（kind=node）+ 10 个 hub（user/ai_role）；321 个谓词 |
| 事实向量 | `_locomo_bench/_wsim/role_*.npy` 与 5 份投影的 5058 个 id 一一对齐，无缺失 |
| 单跳样本 | LoCoMo category 4，共 **418** 题（全部 999 题的分布：cat4 418、cat5 237、cat2 156、cat1 142、cat3 46） |

**与预期不符的一处**：历史产物 `_wsim/rounds.json` 的 round-0 top-30 与"用现存向量重新排序"只有 **23/30** 重合，导致其记录的基线（单跳 gold 命中 49.3%、准确率 65.6%）与本报告重算的基线（52.4%、67.9%）不同。原因应是历史文件由另一批向量/另一次运行生成，本报告统一以现存向量重算，并重新答题+判分，保证所有条件同源。作为交叉验证，线上网关 `conv*/judge.json` 的单跳准确率是 **67.7%**（283/418），与本报告重算的 67.9% 基本一致，说明重算基线可信。

统计口径沿用本仓库此前报告：

- **gold 命中@30**：top-30 中存在一条事实，其与 gold 答案的词元覆盖率 ≥ 0.8（`_wsim`/`_lang_ablation` 同一套 `cover`）；
- **MRR**：第一条 gold 事实排名的倒数（未命中记 0）；
- **准确率**：answer + judge 两个 prompt 与 `_locomo_bench/_wsim_answer.py` 逐字一致，模型 `deepseek-v4-flash`，temperature 0。

## 1. 实验设置

### 1.1 基线

纯余弦 top-30（按角色取该角色约 650~1250 条事实）。线上召回还有 rerank、门槛、实体锚定等环节；离线基线刻意只保留"向量扫描"这一层，以便隔离图增强这一个变量。

### 1.2 方案 1：分词 → BM25 → 实体 BFS 加权

1. 分词：中文用 jieba，英文用 `[a-z0-9]+`，统一小写并去停用词；
2. BM25（k1=1.2，b=0.75）索引每个实体：文档 = 实体名 + 该实体的 hook 别名 + 该实体挂的谓词标签；
3. 取 BM25 得分最高的 5 个实体作为种子（分数归一化到 1.0）；
4. 每个种子各自 BFS：实体—实体边 = 命名 `relation` 边 + 同谓词交会边；实体—事实边 = `has_fact`/`parent_id` + 事实文本提及实体名或 hook；hub 作为连接点带度惩罚，事实是终点；
5. 事实权重 = 各路径 `seed × hop_decay^depth` 的最大值，归一化后 `final = cosine + λ × weight`。

网格 32 组：depth ∈ {1,2}、decay ∈ {0.55,0.7}、λ ∈ {0.03,0.05,0.08,0.1}、max/sum 聚合。

另测一个更实用的变体 **1b**：BM25 直接检索事实，取命中事实提到的实体作为种子，再 BFS。

### 1.3 方案 2：中英谓词对应表 → 谓词 DFS 加权

1. 谓词表 21 个语义类（LIVE / WORK / OWN / PET / VISIT / ATTEND / MEET / MARRY / FAMILY / LIKE / CREATE / WRITE / PLAY / STUDY / TEACH / HELP / GIFT / RECOMMEND / WIN / BUY / COLLAB），每类带中英文表层词与图谓词名根；321 个图谓词中 166 个折叠到已知类，其余按词形回退；
2. query 谓词检测：418 道单跳题中 **262 道**至少命中一类（62.7%），156 道无谓词；
3. 种子：BM25 匹配到的实体 + 命中谓词所连的实体（权重 0.5~0.8）；
4. DFS：谓词类型匹配的边权重 1.0，其余边 0.0/0.25；hop decay 0.5~0.7，depth 2~3；到终点收集实体附着的事实；
5. `final = cosine + λ × weight`。网格 36 组。

### 1.4 对照（关键）

- **随机事实对照**：对方案 2 改动过的 209 道题，把它新增的事实替换成同角色、同数量、同位置的随机事实，答案/判分 prompt 不变；
- **同 prompt 复测**：对其中 100 道题用与基线完全相同的上下文再答一次，测量模型+判分器的复测噪声。

## 2. 结果

### 2.1 检索层：没有提升

| 条件 | gold@30（cat4，418） | MRR | gold@30（谓词子集，262） |
| --- | ---: | ---: | ---: |
| 基线（纯余弦） | 219 / 418 = **52.4%** | **0.309** | 150 / 262 = **57.3%** |
| 方案 1 最佳（depth1、decay0.7、λ0.08、sum） | 219 / 418 = **52.4%** | 0.283 | — |
| 方案 1b 最佳（BM25 事实→实体→BFS） | 220 / 418 = 52.6% | 0.308 | — |
| 方案 2 最佳（depth2、hop0.6、λ0.05） | 219 / 418 = 52.4% | 0.299 | 150 / 262 = **57.3%** |

- 32 组方案 1 配置里没有一组超过 219；方案 1b 最好的 220 只是 +1 题。
- 36 组方案 2 配置里最好也只有 219（与基线打平），谓词子集 150（打平），MRR 全部低于基线。
- 排序位移方向是负的：

| 方案 | gold 排名变好的题 | 变差的题 | 新进 top-30 | 掉出 top-30 |
| --- | ---: | ---: | ---: | ---: |
| 方案 1 最佳 | 13 | **61** | 3 | 3 |
| 方案 2 最佳 | 13 | **41** | 1 | 1 |

方案 1 一共向 top-30 注入了 1282 条新事实，其中只有 34 条含 gold（2.7%）；方案 2 注入 696 条，含 gold 24 条（3.4%）。被强加权（权重 ≥0.5）的事实集合里，gold 的平均精度只有 **2.2% / 2.9%**——用这样的集合去加权重排，净效果必然是"把无关事实抬上来、把 gold 挤下去"。

### 2.2 端到端准确率：看起来涨了，但不能归因于图

| 条件 | cat4（418） | Δ | 显著题对 | 谓词子集（262） | Δ |
| --- | ---: | ---: | ---: | ---: | ---: |
| 基线 | 284 = **67.9%** | — | — | 178 = 67.9% | — |
| 方案 1 | 294 = **70.3%** | +2.4pp（p=0.076） | +18 / −8 | 187 = 71.4% | +3.4pp（p=0.078） |
| 方案 2 | 295 = **70.6%** | +2.6pp（p=0.019） | +15 / −4 | 189 = 72.1% | +4.2pp（p=0.019） |

单看这张表会以为方案 2 有效，但两个对照推翻了这个解释。

**对照 A：随机事实替换。** 在方案 2 实际改动的 209 道题上：

| 条件 | 准确率 |
| --- | ---: |
| 基线 | 140 / 209 = 67.0% |
| 方案 2 | 151 / 209 = **72.2%** |
| 随机事实替换（同数量、同位置） | 151 / 209 = **72.2%** |

方案 2 与随机对照逐题对比是 **7 对 7 平**：图扩展带来的事实并不比随机事实更有用。

另一个佐证是拒答率：基线有 103 题回答 "Not mentioned"，方案 1/2 分别降到 94/92；方案 1 的 18 个"新增答对"里有 14 个原本是拒答。也就是说，一部分"提升"只是上下文变化让模型不再拒答，而判分器对"沾边"答案比较宽松。

**对照 B：同 prompt 复测。** 对其中 100 道题用完全相同的基线上下文重答：

| 条件 | 准确率 |
| --- | ---: |
| 基线（首次） | 75 / 100 = 75.0% |
| 基线（复测） | 81 / 100 = **81.0%** |

100 题翻转 6 题（全部为"错→对"）。也就是说，同一 prompt、同一模型、同一判分器，单次运行的准确率波动就有约 ±6pp。+2.4~2.6pp 的"提升"落在噪声范围内。

## 3. 为什么没有效果：三条硬约束

### 3.1 事实不在实体上，在说话人 hub 上

| 指标 | 数值 |
| --- | ---: |
| 事实总数 | 5058 |
| 能从实体（名字/hook/parent）到达的事实 | 2457（**48.6%**） |
| 只挂在 user/ai_role hub 上、实体侧不可达 | 2601（**51.4%**） |

BFS/DFS 从实体出发，走的是"实体—事实"边；半数事实根本不在这个子图里。要覆盖它们只能穿过 hub，而穿过 hub 就等于给该说话人的几百条事实一起加权（ADR-0175 的 hub 惩罚正是为此），信号被摊平。

### 3.2 BM25 实体匹配的精度不够

418 道单跳题中，只有 **151 道**的 gold 事实提到至少一个图谱实体；在这 151 道里：

| 指标 | 数值 |
| --- | ---: |
| BM25 top-1 命中 gold 事实所提实体 | 34（22.5%） |
| BM25 top-5 含 gold 实体 | 60（39.7%） |

原因是 LoCoMo 单跳题大多在问"某个人"（Caroline / Melanie / Maria…），而这些人在图里是 user hub（名为"主人"）或 ai_role，不是普通实体；BM25 更容易命中"Caroline的朋友 / Caroline的祖国"这类所有格实体，属于假种子。

### 3.3 可达性上限本身就很小

| 方案 | 基线漏掉的题 | 其中 gold 在加权可达集内 | 理论上限 |
| --- | ---: | ---: | ---: |
| 方案 1（BM25 种子，≤2 跳） | 199 | **7** | +7 题（+1.7pp） |
| 方案 2（谓词 DFS，depth 2~3） | 112（谓词子集内） | **8** | +8 题（+1.9pp） |

即使加权完美、没有任何误伤，两个方案能捞回来的题也不到 2 个百分点；而实际加权还会误伤（方案 1 排名变差 61 题 vs 变好 13 题）。

### 3.4 谓词是交会点，不是有向关系

方案 2 的谓词子集共 262 题：

| 指标 | 数值 |
| --- | ---: |
| gold 事实直接挂在"该谓词所连实体"上的题 | 48 / 262 |
| gold 在 DFS 可达集内的题 | 92 / 262 |
| 基线漏掉、且 DFS 可达的题 | 8 / 112 |

图里的 `predicate_link` 把"共享同一谓词"的实体两两连边（LIVES_IN 同时连着好几个实体），它表达"这些实体都参与过这个谓词"，而不是"A 的 LIVES_IN 是 B"。因此 DFS 无法沿"主语→谓词→宾语"定向到答案；它只能在谓词团里扩散，得到的仍是主题相关而非答案相关的事实。

## 4. 谓词表本身是够用的

query 谓词检测覆盖 262/418 单跳题（62.7%），类型分布（多标签）：

| 类型 | 题数 | 类型 | 题数 | 类型 | 题数 |
| --- | ---: | --- | ---: | --- | ---: |
| LIKE | 45 | VISIT | 21 | RECOMMEND | 13 |
| WRITE | 35 | COLLAB | 20 | PET | 12 |
| FAMILY | 33 | PLAY | 20 | STUDY | 9 |
| ATTEND | 33 | GIFT | 15 | WIN | 7 |
| CREATE | 31 | MEET | 14 | TEACH | 5 |
| HELP | 23 | WORK | 14 | MARRY | 3 |
| | | | | LIVE | 3 |

问题不在"识别谓词"，而在"图上没有可用的谓词边"。谓词表可以保留，作为查询理解/候选过滤的一层，但不应驱动图遍历。

## 5. 构造性对照：词法信号应该作用在事实层

既然 BM25 这一路本身有信息，做了一个不做图扩展的对照：BM25 直接检索事实，与余弦用 RRF 融合（k=60/20/10），或做候选并集。

| 条件 | gold@30 | MRR |
| --- | ---: | ---: |
| 纯余弦 | 219 = 52.4% | 0.309 |
| 纯 BM25（事实级） | 199 = 47.6% | 0.311 |
| RRF，k=10 | 220 = 52.6% | **0.338** |
| RRF，k=20 | 221 = 52.9% | 0.332 |
| 并集：余弦前 25 + BM25 前 5 | **222 = 53.1%** | 0.309 |

BM25 单独用命中率更低，但**排序质量（MRR）明显更好**：RRF 把第一条 gold 事实的平均排名从 0.309 提到 0.338（+9%），代价只是命中数 ±1~3 题。这说明词法信号的价值在"把已经在候选池里的 gold 往前排"，而不是"先落到实体、再沿图扩散"。

## 6. 结论与建议

1. **两个方案都不建议在当前 LoCoMo 图上上线。** 方案 1 在单跳上持平基线、排序显著变差；方案 2 在谓词子集上持平、排序变差；端到端的"提升"被随机对照和复测噪声解释。
2. 若目标是"加强检索"，优先级应是：
   - **事实级混合检索**：BM25 + cosine 的 RRF（本次对照 MRR +9%，命中 ±1），不需要建新图；
   - **补齐 fact→entity 边**：抽取阶段把事实里提到的实体写成显式边，让 BFS 真的有路可走；当前 51.4% 的事实是孤岛；
   - **谓词改成三元组**：把 `predicate_link` 的共享交会点升级为 `subject -[predicate]-> object` 有向边，谓词 dfs 才可能定向；
   - **评测加对照**：任何准确率对比都应带"随机事实替换"对照和"同 prompt 复测"，否则 ±6pp 的差异无法解释。
3. 谓词对应表（21 类、中英别名）本身可以保留：它覆盖了 62.7% 的单跳题，可用于查询理解、候选过滤或谓词级重排，但不要用它驱动图遍历。

## 8. 局限

- gold 命中用词元覆盖 ≥0.8，跨语言/改写敏感；它衡量"答案字面在不在上下文里"，不衡量"模型能否用它答题"。这也正是出现"命中率不涨、准确率涨"的原因之一。
- 离线基线没有线上 rerank/门槛；线上把图扩展候选再过一遍 rerank，结果可能不同（但可达性上限 7/8 题不会变）。
- 网格在同一批 418 题上调参（in-sample），对方案是有利的；即便如此仍未超过基线。
- 复测只覆盖 100 题；±6pp 是这批题上的估计，不是精确的噪声模型。
